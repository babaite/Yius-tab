# README screenshot sources

`newtab-light.png` and `newtab-dark.png` are actual captures of the extension UI rendered by Chrome from the project's preview code at a 1440×768 CSS viewport and 2× device scale factor. The resulting images are 2880×1536.

The fixture contains 40 fixed public websites. It does not read the user's bookmarks or display personal home-page content. The captures were taken after a 205 CSS-pixel scroll, with the scrollbar visible and the top gradient blur active.
